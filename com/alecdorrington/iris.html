final case class Chat(messages: List[Message] = ..., system: Option[String] = ...)

The full history of a conversation with a model, sent whole with every request. To continue a conversation, append the model's reply and the next user message, then send the chat again:

The full history of a conversation with a model, sent whole with every request. To continue a conversation, append the model's reply and the next user message, then send the chat again:

for
 first  &lt;- client.send(chat)
 next    = chat.assistant(first.text).user("Tell me more.")
 second &lt;- client.send(next)
yield second

A chat should end with the user's message: one ending with the assistant's asks the model to continue its own reply. An empty chat, a message of breakpoints alone, or a reply that a newer Anthropic model would have to continue fails with LlmError.Unsendable before any request is made.

Value parameters

messages

The messages exchanged so far, oldest first.

system

The system message, if any, setting the model's general behaviour.

enum Effort

The thought a thinking model should give a request, from least to most. Less is quicker and cheaper, and leaves more of the token limit for the answer; more may answer a hard request better. A model that cannot be told refuses the request with LlmError.Unsuccessful.

The thought a thinking model should give a request, from least to most. Less is quicker and cheaper, and leaves more of the token limit for the answer; more may answer a hard request better. A model that cannot be told refuses the request with LlmError.Unsuccessful.

OpenAI treats Max as High; Gemini is sent a thinking-token budget.

sealed trait LlmModel

A model Iris can prompt. Each belongs to the one provider which serves it, so a model is never sent to a provider that does not have it. The models Iris lists are constants (LlmModel.ClaudeSonnet5_5), so a name which is not one is refused when it is read rather than when a request is spent finding out; any other is named with its provider, as LlmModel.Other.

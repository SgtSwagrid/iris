final case class Above(tokens: Int, rates: Rates)

Rates for a request whose prompt is longer than some number of tokens, which apply to the whole of it. The prompt is every token of the request, read from the cache or not, as Anthropic says it counts it: OpenAI and Google do not say whether they count cached tokens.

Value parameters

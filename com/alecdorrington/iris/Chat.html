Chat

com.alecdorrington.iris.Chat
See theChat companion object
final case class Chat(messages: List[Message] = ..., system: Option[String] = ...)

The full history of a conversation with a model, sent whole with every request. To continue a conversation, append the model's reply and the next user message, then send the chat again:

for
 first  &lt;- client.ask[String](chat)
 next    = chat.assistant(first).user("Tell me more.")
 second &lt;- client.ask[String](next)
yield second.value

Asked of a chat ending with the assistant's message, the model is told what to answer in a message of the user's after it, and so answers afresh rather than continuing its own reply. A chat with no messages, a message of breakpoints alone, or no message of the user's fails with LlmError.Unsendable before any request is made.

Value parameters

messages

The messages exchanged so far, oldest first.

system

The system message, if any, setting the model's general behaviour.

def cacheable: Chat

The prefix of this chat to cache: everything up to and including its last Part.CacheBreakpoint, followed where needed by a minimal user message so that it can be sent. Without a breakpoint, it holds no messages and so cannot be sent.

Unsuccessful

com.alecdorrington.iris.api.ApiError.Unsuccessful
final case class Unsuccessful(provider: String, status: StatusCode, detail: String) extends ApiError

An unsuccessful HTTP status from the provider that sending the request again would not change, and so never sent again: a refused key, a request the provider cannot take, a spent quota or credit, or any the provider marks not to retry (x-should-retry: false).

The response body.

The name of the provider, for display.

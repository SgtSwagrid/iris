ProviderModel

com.alecdorrington.iris.api.ProviderModel
trait ProviderModel

A model Iris can prompt. Each belongs to the one provider which serves it, so a model is never sent to a provider that does not have it. The models Iris lists are constants of their provider's (AnthropicModel.ClaudeSonnet5_5), and any other is named by its provider, as AnthropicModel.of(id).

ApiConfig

com.alecdorrington.iris.api.ApiConfig
See theApiConfig companion object
final case class ApiConfig(key: Option[String] = ..., baseUrl: Option[String] = ..., timeout: FiniteDuration = ..., maxRetries: Int = ..., backoff: FiniteDuration = ..., patience: FiniteDuration = ...)

How a provider's API is reached: the defaults every request takes.

Value parameters

backoff

The wait before sending a request again where the provider asks for none, doubling each time, less up to half at random, and else added up to once at random to the wait it asks for.

baseUrl

The origin to send requests to, or None for the provider's own.

key

The API key, or None for the provider's own environment variable, such as ANTHROPIC_API_KEY, read when a service is made.

maxRetries

The most times a request is sent again after the first, where the provider refuses or fails it for now: 0 sends each once.

patience

The longest a request is waited out in all, after which its last refusal is given.

timeout

The longest a request is waited for: a whole response from sending it to reading it, and each next part of a streamed one.

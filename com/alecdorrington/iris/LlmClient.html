trait LlmClient[F[_]]

A provider-agnostic client for large language models, constructed with LlmClient.resource or LlmClient.fromEnv.

Clients are stateless: the whole conversation travels with each Chat, so a conversation continues by appending to the chat and sending it again.

final def ask[A](chat: Chat, options: ReplyOptions = ..., attempts: Int = ...)(using evidence$1: Schema[A], MonadThrow[F]): F[Answer[A]]

Asks the model for its next reply to a chat, with an answer of a type read from it: the one way a caller has a reply, as count and warm have none to read. It needs F to raise errors, as every client's effect can.

Asks the model for its next reply to a chat, with an answer of a type read from it: the one way a caller has a reply, as count and warm have none to read. It needs F to raise errors, as every client's effect can.

Every type is asked for alike, String as much as a case class of one's own: the model is told the type's JSON Schema, closing the chat's last user message, and its reply read as JSON conforming to it. A reply that cannot be read is followed by why, and the model asked again, until one can be or the attempts run out, but not where asking again could not help: a reply cut off at the token limit, which is never read, stopped for a reason of the provider's, such as a refusal, or saying nothing. A reply asking for a tool is given with no answer. A chat in which the user says nothing fails with LlmError.Unsendable before any request. Every attempt goes through send, so a wrapper overriding it sees each.

case class Person(name: String, age: Int)

client.ask[Person](Chat.of("Invent a person.")).map(_.value)

Type parameters

A

The type of the answer.

Value parameters

attempts

The most answers to ask for, three unless given, which must be at least one, as the effect otherwise fails with an IllegalArgumentException.

chat

The conversation so far, including any system message.

options

The per-request options, alike for every attempt; unset fields fall back to the configuration or the provider's defaults.

Attributes

Returns

An effect producing the last reply with its answer, alike for every type: its text, why the model stopped, the usage of every attempt and the tools it asked for. It fails with LlmError.Unreadable where the last reply could not be read either.

def warm(chat: Chat, options: ReplyOptions = ...): F[Answer[Nothing]]

Writes the Chat.cacheable prefix of a chat into the provider's cache, with as short a reply as the provider allows. Requests sharing the prefix and sent at once afterwards then all read it, where unwarmed each would write its own. Fails with LlmError.Unsendable when the chat has no Part.CacheBreakpoint.

A value of a type as an AgentService gives it, alike for every type: the value, as soon as everything in it but its streams is read, and every round it took, once the last ends.

A value of a type as an AgentService gives it, alike for every type: the value, as soon as everything in it but its streams is read, and every round it took, once the last ends.

Type parameters

A

F

Value parameters

cancel

Stops reading the last response, as QueryResponse.cancel does.

iterations

Every round the request took, oldest first, once the last ends: each a query's responses up to and including one asking for tools, and the last those the value was read from.

value

The value read from the last response. A response asking for a tool the service was not given, or for any in the last round allowed, is asked again, as a query asks again after one it cannot read.

trait AgentService[F[_]]

A value of a type, with tools run wherever the model asks for them, as RunnableTools say, until it gives the value. Each round asks again with the tools' results, and closes its request with a cache breakpoint, so that the rounds before it are read from the cache. A value holding a stream arrives through two tools of Iris's own, emit, one element a call, and done, so that the model may call tools between its elements. The rounds are as many as the model asks for unless AgentConfig.maxIterations caps them, so that a budget on the prompt service bounds what they spend. A service is made from the prompt service it asks through, as prompt.agent(tools*), and reads its value as a query does.

final case class RunnableTool[F[_]](tool: Tool, run: String => F[String])

A tool the model may ask to have run, with what running it does: given to an AgentService, it is offered to the model and run wherever the model asks for it, the model then told its output and asked to go on. What the tool does, and whether it may, is the host's, as run decides.

A tool the model may ask to have run, with what running it does: given to an AgentService, it is offered to the model and run wherever the model asks for it, the model then told its output and asked to go on. What the tool does, and whether it may, is the host's, as run decides.

Type parameters

Value parameters

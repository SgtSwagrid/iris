trait Content[A]

What may be said to the model: how a value is written as text in a message, wherever a Conversation takes one. Values of different kinds mix freely there, each said as its own type's content, beside parts given as themselves:

What may be said to the model: how a value is written as text in a message, wherever a Conversation takes one. Values of different kinds mix freely there, each said as its own type's content, beside parts given as themselves:

conversation.userSays("Review this draft.", draft, MessagePart.CacheBreakpoint, "Be brief.")

A String is said as itself. A value of a type with a Schema is said as JSON as that writes it, so that it is written as the schema the model may be told describes it, and a value of another type with a circe Encoder as that writes it. A type given a content of its own is said as that says it:

given Content[Money] = money => MessagePart.Text(s"${money.amount} USD")

No other value can be said, and one holding an fs2 Stream has a schema but cannot be: saying it throws, as its stream would have to be run. Say a list of the stream's elements instead.

final case class QueryResponse[F[_], +A](value: A, attempts: F[List[PromptResponse]], cancel: F[Unit], conversation: F[Conversation])

A value of a type as a QueryService gives it, read from what the model wrote, alike for every type: the value, as soon as everything in it but its streams is read, and every prompt the query took, once the last ends.

A value of a type as a QueryService gives it, read from what the model wrote, alike for every type: the value, as soon as everything in it but its streams is read, and every prompt the query took, once the last ends.

Type parameters

A

The type of the value.

F

The effect type.

Value parameters

attempts

Every response the query took, oldest first, once the last ends: the last is the one the value was read from. Where the last cannot be read to its end after the value was given, it fails as the value's streams not yet ended do: with QueryError.Unreadable where what the model wrote cannot be read, and as the request fails where that fails partway.

cancel

Stops reading the last response, where it is still being read once the value was given, as it is for a type holding a stream: its streams not yet ended, and its attempts, then fail with an IllegalStateException. Otherwise it does nothing, as does a cancel once the response has ended.

conversation

The conversation as the model saw it last, with its last response, its instructions included, to go on from, once the last response ends.

value

The value read from the last response. A response asking for a tool is asked again, as one that cannot be read is, as a query runs none. Each fs2.Stream within it delivers its elements as the model writes them, each time it is read, from the first.

trait QueryService[F[_]]

A value of any type with a Schema, String included, read from what the model writes, alike for every type: the model is told the type's JSON Schema, closing the conversation's last message of the user's, once, and what it writes is read as JSON conforming to it. A response that cannot be read is followed by why, and the model asked again, until one can be or the attempts run out, but not where asking again could not help: a response cut off at the token limit, stopped for a reason of the provider's, such as a refusal, or saying nothing. A response asking for a tool is given with no value. A service is made from the prompt service it sends through, as prompt.query.

final class Schema[A]

How a type's values travel to and from the model as JSON: how a value is written, how one is read back, and the JSON Schema the model is told they conform to. QueryService.send asks for a type with one, and Content says one.

How a type's values travel to and from the model as JSON: how a value is written, how one is read back, and the JSON Schema the model is told they conform to. QueryService.send asks for a type with one, and Content says one.

Strings, numbers, Booleans, options, lists, vectors, sequences, sets, maps keyed by strings, tuples, eithers, unions and literal types have one, and so does every case class, sealed trait and enum whose fields have one, derived wherever it is needed, but for one with a circe Encoder of its own, which is said as that writes it:

case class Person(name: String, age: Int, nickname: Option[String] = None)

client.ask[Person](Conversation.userSays("Who wrote Middlemarch?"))

derives Schema derives one once, beside its type, rather than wherever it is needed, even for a type with an Encoder of its own, and names any field whose type has none. Circe's Json has none, as it would tell the model nothing.

A case class, or a named tuple, is an object of its fields, of which one that is optional or has a default may be left out, and is read as None or its default. A sealed trait or enum whose cases have no fields is the name of one of them, as "Red"; any other is an object holding one case under its name, as {"Circle":{"radius":1.0}}, as an Either holds its value under Left or Right, and a union under the name of its alternative, as {"Int":1}, which a value's class must tell, but for a union of literal types alone, which is one of their values. A tuple is an array of its elements, and an fs2 Stream an array of its values, which QueryService.send delivers as the model writes them, but which cannot be said as JSON. A recursive type refers to itself through definitions in the schema, each type told apart by its full name and type arguments, so that Tree[Int] and Tree[String] are each defined.

The schema describes a derived type, each of its cases and each of its fields as its Scaladoc does: a type or case by its description, and a field by its class's @param tag, followed by its type's description. Code examples are left out, and links written as their labels. A comment is read only where its type is compiled alongside, as it always is for derives Schema, or anywhere under -Xread-docs, and never under -Xdrop-docs.

In JavaScript, a reply's numbers are read as doubles, so a Long, BigInt or BigDecimal beyond 2^53^ is read imprecisely.

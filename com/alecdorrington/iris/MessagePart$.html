case object CacheBreakpoint extends MessagePart

The end of a prefix for the provider to cache: everything before it, the system message included, is shared by many requests. It says nothing to the model.

The end of a prefix for the provider to cache: everything before it, the system message included, is shared by many requests. It says nothing to the model.

Anthropic caches only at breakpoints, and refuses a chat whose breakpoints mark more than four blocks with ModelError.Unsendable, but for any closing the chat, which mark its last block only where the others leave room; OpenAI and Gemini cache long prefixes by themselves. A prefix too short for the provider is not cached. Requests sent at once cannot read one another's writes, so call ModelClient.warmCache before a batch. An ask running tools closes each request after a round of them with one of its own, so that the rounds before it are read from the cache.

final case class ToolCall(id: String, tool: String, arguments: Json, signature: Option[String] = ...) extends MessagePart

A call by the model for a tool to be run. It is part of the model's message, and is sent back with the conversation as the reply gave it.

A call by the model for a tool to be run. It is part of the model's message, and is sent back with the conversation as the reply gave it.

Value parameters

arguments

The arguments, as described by Tool.parameters.

id

The provider's identifier of the call, by which its result is matched. Where Gemini gives none, the tool's name stands in, and is not sent.

signature

An opaque token the provider gave with the call, sent back with it unchanged: Gemini's thought signature, which its thinking models need to go on with their reasoning. No other provider gives one.

tool

The name of the Tool to run.

def of[A](value: A)(using A: Content[A]): MessagePart

Creates a part saying a value, as its Content says it: text as text, and a value with a schema or an encoder as JSON. A value given to a chat or message is said so already; this makes parts of a list of values to give it, as chat.userSays(values.map(MessagePart.of)*).
